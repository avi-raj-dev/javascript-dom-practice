# DOM Practice - Part 2

This folder contains JavaScript practice exercises focused on DOM manipulation and event handling.

## Concepts Covered

- Selecting HTML elements using JavaScript DOM methods
- Modifying element content and attributes
- Changing CSS styles dynamically
- Creating and removing HTML elements
- Handling user interactions using event listeners
- Responding to events such as clicks and other user actions

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

These exercises were created to strengthen my understanding of the JavaScript Document Object Model (DOM) and how JavaScript interacts with HTML elements to create dynamic and interactive web pages.
