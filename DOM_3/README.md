# DOM Practice - Part 3

This folder contains JavaScript DOM practice projects focused on event propagation, event handling, and DOM manipulation.

## 1. Event Bubbling

Demonstrates **event bubbling** in JavaScript, where an event triggered on a child element propagates upward through its parent elements.

**Concepts covered:**
- Event bubbling
- Event propagation
- `event.target` and `event.currentTarget`
- JavaScript event listeners

## 2. Tic-Tac-Toe Game

A simple Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

**Features:**
- Two-player gameplay using X and O
- Winner detection based on winning combinations
- Draw detection
- Restart game functionality

**Concepts covered:**
- DOM manipulation
- Event handling
- Arrays and conditional statements
- Game logic and state management

## Technologies Used

- HTML
- CSS
- JavaScript

## Purpose

These projects were created for practicing JavaScript DOM concepts and understanding how user interactions can be handled dynamically in web applications.
